# «Ваш Кристалл незабываемости» — урок с фотографиями

Генератор создаёт PPTX и PDF с фотографией на каждом слайде. Пустая левая зона — 4,5 дюйма; фото справа — 3,5 × 5 дюймов; нижняя маска закрывает последние 0,5 дюйма.

```bash
python -m pip install -r requirements-lesson.txt
python generate_lesson.py
python generate_lesson.py --input lecture.md
python generate_lesson.py --push
```

`lesson_content.json` хранит исходную речь и темы. Слайды делятся по смыслу и доступному месту, а Notes сохраняют все слова в исходном порядке. 650 — предел будущей программы, а не требование искусственно размножать этот короткий урок. Предел можно изменить через `--max-slides`.

По умолчанию используется бесплатный открытый каталог фотографий с подбором по категориям. Ссылки на источники и лицензии находятся в `photo_catalog.json`, `PHOTO_CREDITS.md` и `image_sources.json`. Каталог можно расширить собственными разрешёнными фотографиями. Для этого облачного запуска прямой Unsplash недоступен по сетевой политике; использованы доступные исходники открытых коллекций.

Для поиска через Unsplash API настройте секрет окружения `UNSPLASH_ACCESS_KEY` и разрешите доступ к `api.unsplash.com` и `images.unsplash.com`, затем используйте `--provider unsplash`. Ключ не записывается в репозиторий. Результаты поиска кэшируются по тематическим запросам; изображения повторно не скачиваются при повторной сборке. Не требуется 650 запросов к API на 650 слайдов. Одно изображение может использоваться повторно. API-вызовы учитывают лимиты и выполняют download-tracking при скачивании.

Оригиналы фотографий лежат в игнорируемом каталоге `work/photo-cache`. В готовые PPTX/PDF встроены сами изображения; доступ к сети для просмотра не нужен. Для портретного контейнера выполняется только кадрирование, без ретуши. Файлы шрифтов Georgia, Georgia Italic и Arial можно передать через `--fonts-dir`; иначе они скачиваются при первом запуске.
