# «Ваш Кристалл незабываемости» — ИИ-образы

```bash
python -m pip install -r requirements-lesson.txt
python generate_lesson.py
python generate_lesson.py --push
```

Сборка использует сгенерированные художественные метафоры из `assets/ai`, без поиска стоковых фотографий. Все изображения встроены в PPTX/PDF. Лекция хранится в `lesson_content.json`; текст Notes сохраняется полностью и делится по содержанию экранов. Поддерживается входной Markdown через `--input lecture.md` и будущая программа до 650 слайдов без искусственного размножения текущего урока.

Сетка: левая зона 4,5″ пустая; карточки — 4,7″ шириной на позиции 4,5″; изображение — 3,3 × 5″ на позиции 9,5″ / 1,5″; цитаты отделены внизу. Маска номера страницы накладывается последним слоем, поля номера удалены из шаблона. Встроенные проверки подтверждают эти условия и неизменность речи автора.

Для новой индивидуальной ИИ-генерации на каждом слайде настройте секрет `OPENAI_API_KEY` и сетевой доступ к `api.openai.com`, затем выполните:

```bash
python generate_lesson.py --visual-mode per-slide
```

Детали промптов, палитры, API и двух режимов находятся в [ART_DIRECTION.md](ART_DIRECTION.md). Ключи не хранятся в коде. Каталог образов — `art_catalog.json`, отчёт по каждому экрану — `image_sources.json`. Georgia/Arial можно передать через `--fonts-dir`; иначе они скачиваются при первой сборке.
