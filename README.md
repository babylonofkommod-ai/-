# «Ваш Кристалл незабываемости» — текстовый урок

```bash
python -m pip install -r requirements-lesson.txt
python generate_lesson.py --fonts-dir /path/to/fonts
python generate_lesson.py --fonts-dir /path/to/fonts --push
```

На слайдах только текст: графитовый фон, тёмные карточки, золотые заголовки Georgia, белые тезисы Arial и отдельные нижние цитаты Georgia Italic. Генерации изображений, поиска, HTTP-запросов и вставки картинок в коде нет. Никаких ключей API не требуется.

Текстовые карточки: `left = Inches(4.5)`, `width = Inches(8.3)`. Левая зона под видео полностью пустая. Ширина заголовков и цитат соответствует той же сетке. Нижняя маска: `left=0`, `top=7.0`, `width=13.333`, `height=0.5` дюйма. Она накладывается последним объектом и не имеет рамки; поля номеров также удалены из мастер-слайдов и макетов.

`lesson_content.json` содержит исходную речь. Авторазделение учитывает число тезисов и доступную высоту; Notes сохраняют все слова в исходном порядке. Поддерживаются Markdown через `--input lecture.md` и будущая программа до 650 слайдов без искусственного размножения текущего урока.

Для полностью локальной сборки нужны `georgia.ttf`, `georgiai.ttf`, `arial.ttf` в папке `--fonts-dir` или стандартных системных каталогах. Проверки подтверждают отсутствие картинок в PPTX/PDF, ширину карточек 8,3″, отсутствие наложений на цитаты, пустую левую зону и однотонную нижнюю маску. Счётчик страниц интерфейса PDF-просмотрщика не является частью слайда.
