# «Ваш Кристалл незабываемости» — векторная инфографика

```bash
python -m pip install -r requirements-lesson.txt
python generate_lesson.py --fonts-dir /path/to/fonts
python generate_lesson.py --fonts-dir /path/to/fonts --push
```

Генератор работает локально, без генерации, поиска, загрузки и вставки изображений. Все схемы состоят из редактируемых фигур PowerPoint; PDF содержит текст и векторные элементы.

Автоматическая верстка определяется содержанием речи: противопоставления — две вертикальные карточки и золотой connector; этапы — горизонтальная цепочка со стрелками и переносом длинной цепи; соответствия «грань → след» — параллельные строки связей; три тезиса — плитки; остальные списки — карточки с нарисованными золотыми ромбами. Авторские мысли оформляются отдельными рамками с левой золотой линией, Georgia Italic 18 pt. Все выбранные фразы берутся из речи автора.

Рабочая зона: `left=4.5`, `width=8.3` дюйма. Подколонки, узлы, стрелки и маркеры находятся строго внутри этой зоны. Левая часть до 4,5″ пуста. Каждый смысловой блок проходит проверку пересечений и выхода за пределы; исходный текст Notes сохраняется полностью и в исходном порядке. Вход — `lesson_content.json` или Markdown через `--input lecture.md`; будущая программа может содержать до 650 слайдов без искусственного дублирования урока.

Графитовая маска `left=0`, `top=7.0`, `width=13.333`, `height=0.5` дюйма добавляется последним объектом без рамки. Поля нумерации удаляются из мастеров и макетов. Проверка PDF подтверждает однотонность нижней полосы и всей зоны для видео. Счётчик страниц приложения просмотра не является частью слайда.

Нужны локальные `georgia.ttf`, `georgiai.ttf`, `arial.ttf` в `--fonts-dir` или стандартном системном каталоге. Ключи API и изображения не используются.
