# Художественная система урока

Для этой сборки создана серия из шести ИИ-образов: кристалл с золотой жилой, дымовой след, лёгкий шёлк, обсидиановые плоскости, световые грани и разомкнутое золотое кольцо. Они сгенерированы через OpenAI image generator и включены в репозиторий в `assets/ai`; стоковые фотографии и их каталоги удалены из текущей версии.

Каждый слайд получает тематический промпт с обязательными тегами: `luxury dark mood art`, `surreal gold crystal`, `fine art photography`, `vogue aesthetic minimal`. Палитра: графит, чёрный, дымчатый серый и приглушённое золото. Бытовые интерьеры, люди, офисные схемы, яркие цвета, логотипы и белые рамки исключены.

По умолчанию используется режим `shared`: подходящий образ выбирается по содержанию лекции из готовой художественной серии. Это позволяет пересобирать весь урок без ключа API и сохранять единый стиль. Изображения могут повторяться по теме; это не 22 независимые генерации.

Для отдельной генерации по каждому слайду предусмотрен режим `--visual-mode per-slide`. Он вызывает OpenAI Images API через `requests`, получает изображение в `BytesIO`, кэширует его по хешу промпта и встраивает в PPTX/PDF. Требуются защищённый `OPENAI_API_KEY` и разрешённый доступ к `api.openai.com`. Модель задаётся через `OPENAI_IMAGE_MODEL`, по умолчанию `gpt-image-1`. При отсутствии доступа нет подмены стоком или случайными ссылками.

Геометрия: фото `left=9.5, top=1.5, width=3.3, height=5.0` дюйма; карточки `left=4.5, width=4.7`. Золотая цитата располагается отдельным нижним блоком. Маска `left=0, top=7.0, width=13.333, height=0.5` накладывается последним объектом; поля нумерации удаляются также из мастер-слайдов и макетов. Проверки относятся к содержимому файлов, а не к счётчику страниц интерфейса PDF-просмотрщика.
